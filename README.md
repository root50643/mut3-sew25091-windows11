# M.U.T.-3／SE：Windows 11 安裝教學

**先雙擊 `Install-Prerequisites.cmd` 準備 Windows 元件，再手動執行原廠 `MUT3_Install.bat` 安裝主程式。**

本專案提供前置元件助手。主程式的解壓、安裝、舊版移除及重新開機，依下方步驟操作。

> SEW26061-00 的本輪安裝仍待完成驗收；目前不能保證新版已在本機成功安裝。

## 需要準備什麼

- Windows 11 **64 位元（x64）** 電腦、管理員權限與網路連線。
- [下載本專案 ZIP](https://github.com/root50643/mut3-sew25091-windows11/archive/refs/heads/main.zip)，或在 GitHub 點 **Code → Download ZIP**。
- 自行取得原廠 **`SEW26061-00.zip`**，供稍後手動安裝主程式。本專案沒有附原廠主程式。
- 儲存工作；若有要保留的 M.U.T. 車輛記錄或設定，先備份。

將本專案 ZIP 按右鍵選「**全部解壓縮**」，保留這些檔案：

```text
專案資料夾\
├─ Install-Prerequisites.cmd   ← 雙擊這個檔案準備元件
├─ Install-MUT.cmd             ← 相容入口，現在也只準備元件
├─ ps2DLC.zip                  ← 專案已附，保留原樣
├─ scripts\                   ← 必須保留整個資料夾
├─ docs\
└─ README.md
```

**不要在 ZIP 預覽視窗直接執行。** 前置元件助手不需要原廠 ZIP；`SEW26061-00.zip` 可以放在其他位置，也不用將 `ps2DLC.zip` 手動解壓。

## 1. 一鍵準備前置元件

1. 關閉 M.U.T. 與其他安裝視窗。
2. 雙擊 **`Install-Prerequisites.cmd`**。
3. Windows 詢問「是否允許此應用程式變更您的裝置？」時，按「**是**」。
4. 等待「**前置元件準備完成**」結果視窗。元件已齊全時會略過重複處理；遇到問題時，視窗會說明原因及日誌位置。
5. 若要求重啟，儲存工作並從 Windows 選「**重新啟動**」。回來後再次雙擊同一個檔案，確認前置檢查通過。

**前置檢查通過後，請繼續下方原廠安裝步驟。** 助手不會自動開啟或移除 M.U.T. 主程式。

## 2. 解壓原廠主程式

將 `SEW26061-00.zip` 完整解壓到 `C:\MUT-Install`，確認入口檔案位於：

```text
C:\MUT-Install\SEW26061-00\MUT3_Install.bat
```

如果解壓後多包了一層同名資料夾，請找到真正包含 `MUT3_Install.bat` 的那一層。不要只把單一 BAT 檔拉出來執行。

### 已有舊版時

**SEW25091 需要先依原廠說明解除安裝，再安裝新版。** 確認需要的資料已備份後，使用原本 SEW25091 安裝包中的 `UNINSTALLER\UNINST.BAT`，按右鍵選「**以系統管理員身分執行**」，依原廠提示完成，再重新啟動 Windows。

其他舊版本請先查閱新版安裝包隨附的更新手冊，確認適用的更新方式。不要自行刪除程式資料夾代替解除安裝。

## 3. 手動執行原廠安裝

在 `C:\MUT-Install\SEW26061-00` 中，對 **`MUT3_Install.bat`** 按右鍵，選「**以系統管理員身分執行**」；出現 Windows 管理員授權時按「**是**」。

| 出現的畫面 | 請這樣操作 |
| --- | --- |
| **M.U.T.-III Version Checker** | 按「**是／Yes**」。 |
| 地區選擇 | 選 **Other**，再按 **Install**。 |
| 裝置驅動程式安裝精靈 | 按「**下一步／Next**」，結束後按「**完成／Finish**」。 |
| 安裝完成、要求重啟 | 儲存工作，從 Windows 選「**重新啟動**」。 |
| PowerShell 2.0 或資料庫錯誤 | 先保留錯誤畫面，依下方「遇到問題時」處理。 |

安裝可能開啟多個原廠視窗，請依序完成，不要同時啟動第二份安裝器。

## 4. 重啟後，開啟兩個程式

從桌面分別開啟兩個程式，確認主畫面版本：

| 桌面捷徑 | 主畫面底部應顯示的版本 |
| --- | --- |
| **M.U.T.-3**（傳統版） | **PRG23061-03** |
| **M.U.T.-3_SE** | **SEW26061-00** |

首次開啟若顯示使用條款，請閱讀並依畫面操作。**兩個程式都要能進入主畫面；只有桌面捷徑不代表安裝完成。**

若傳統版詢問要用哪個程式開啟，選 **Microsoft Windows Based Script Host**，再按「**一律／Always**」，然後重新開啟桌面的 **M.U.T.-3**。

## 遇到問題時

| 提示或情況 | 處理方式 |
| --- | --- |
| 找不到 `scripts` 或 `ps2DLC.zip` | 重新完整解壓本專案，保留原本的檔案與資料夾結構。 |
| 檔案校驗失敗 | 重新下載專案；不要手動修改檔案或略過檢查。 |
| 要求重啟，或顯示 `3010` | 儲存工作並「重新啟動」，再執行前置元件助手。 |
| 已有另一個安裝程序執行中 | 回到原本視窗完成操作，先不要開第二份。 |
| 原廠詢問是否只安裝 SE | 若需要兩個版本，先取消，完成前置元件處理後再依原廠提示重試。 |
| `Failed to setup databases`／`Instance does not exist` | 保留錯誤與日誌，等原廠安裝流程結束後，再執行前置元件助手檢查。這類錯誤可能需要另外修復，不能只看捷徑判斷成功。 |
| 傳統版沒有主畫面 | 確認已選 **Windows Based Script Host → 一律／Always**；仍失敗時保留錯誤訊息。 |

需要協助時，可到 **[GitHub Issues](https://github.com/root50643/mut3-sew25091-windows11/issues)** 提供錯誤截圖、Windows 版本及進行到哪一步。前置元件日誌位於 `C:\MUT-Install\prerequisite-logs`，結果視窗也會列出本次路徑；分享前請移除個人或車輛資料。
