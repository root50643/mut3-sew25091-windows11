# M.U.T.-3／SE：Windows 11 安裝教學

**下載本專案 → 放入 `SEW25091.zip` → 雙擊 `Install-MUT.cmd`，依畫面提示完成安裝。**

安裝助手會處理必要元件與安裝檢查；您只需確認管理員授權、原廠安裝選項，並在需要時重新開機。

## 安裝前準備

- Windows 11 **64 位元（x64）** 電腦、管理員權限與網路連線。
- 自行準備原廠 **`SEW25091.zip`** 安裝包，本專案沒有附這個檔案。
- 儲存工作；若電腦已有 M.U.T. 資料，請先備份。

`ps2DLC.zip` 已隨本專案提供，保留原樣即可，不用另外下載或手動執行裡面的檔案。安裝部分 Windows 元件時仍可能需要網路。

## 1. 下載專案並放好安裝包

1. **[下載本專案 ZIP](https://github.com/root50643/mut3-sew25091-windows11/archive/refs/heads/main.zip)**，或在 GitHub 點 **Code → Download ZIP**。
2. 對下載的專案 ZIP 按右鍵，選「**全部解壓縮**」。
3. 打開解壓後的資料夾，將原廠 `SEW25091.zip` 放在 `Install-MUT.cmd` 旁邊。

檔案位置應如下，其他專案檔案也請保留：

```text
專案資料夾\
├─ Install-MUT.cmd      ← 雙擊這個檔案開始
├─ SEW25091.zip         ← 您自行放入的原廠安裝包
├─ ps2DLC.zip           ← 專案已附，保留原樣
├─ scripts\            ← 必須保留整個資料夾
├─ docs\
└─ README.md
```

**請在解壓後的資料夾操作，不要直接在 ZIP 預覽視窗執行。** 原廠 `SEW25091.zip` 不用先解壓，助手會自動處理。

## 2. 雙擊開始安裝

雙擊 **`Install-MUT.cmd`**。Windows 詢問「是否允許此應用程式變更您的裝置？」時，按「**是**」。

助手會先檢查電腦與檔案，再開始安裝。解壓與安裝需要一些時間，請保留視窗並依提示等候，不要重複開啟。

若這台電腦已正常安裝，助手會進行檢查與程式開啟確認，不會重新安裝。

## 3. 依畫面選擇

| 出現的畫面 | 請這樣操作 |
| --- | --- |
| **M.U.T.-III Version Checker** | 按「**是／Yes**」。 |
| 地區選擇 | 選 **Other**，再按 **Install**。 |
| 裝置驅動程式安裝精靈 | 按「**下一步／Next**」，結束後按「**完成／Finish**」。 |
| 失敗安裝的清理確認 | 確認已備份資料，核對提示後再繼續；不確定時先取消。 |
| 重新啟動提示 | 依下一節操作。 |

地區請選 **Other**：

![地區選擇畫面：選 Other，再按 Install](docs/images/02-select-other.png)

## 4. 重新開機後，再點同一個檔案

當助手要求重啟時：

1. 儲存工作，從 Windows 選「**重新啟動**」。
2. 重新登入後，回到原專案資料夾。
3. 再次雙擊 **`Install-MUT.cmd`**，讓助手繼續。

安裝或失敗重裝期間可能需要重啟不只一次，每次都照這個方式接續。助手不會自動重新開機，也不需要您另行執行 `UNINST.BAT`。

## 5. 開啟兩個程式，確認安裝完成

依助手提示，從桌面分別開啟兩個程式：

| 桌面捷徑 | 主畫面底部應顯示的版本 |
| --- | --- |
| **M.U.T.-3**（傳統版） | **PRG23061-03** |
| **M.U.T.-3_SE** | **SEW25091-00** |

首次開啟若顯示使用條款，請閱讀並依畫面操作。**看到兩個正確的主畫面後，再在助手中回答「是」**；若沒有成功開啟或版本不符，請回答「否」。

### 傳統版詢問要用哪個程式開啟時

選 **Microsoft Windows Based Script Host**，再按「**一律／Always**」，然後重新開啟桌面的 **M.U.T.-3**。不要選文字編輯器或瀏覽器。

## 遇到問題時

| 提示或情況 | 處理方式 |
| --- | --- |
| 找不到 `SEW25091.zip` | 將原廠 ZIP 放在 `Install-MUT.cmd` 旁，確認沒有多包一層資料夾。 |
| 檔案校驗失敗／版本不符 | 確認原廠安裝包版本是 SEW25091，並重新取得提示有問題的檔案；不要略過檢查。 |
| 要求重啟，或顯示 `3010` | 儲存工作並「重新啟動」，回來再雙擊同一入口。 |
| 已有另一個安裝程序執行中 | 回到原本的視窗繼續，先不要開第二份。 |
| PowerShell 2.0、資料庫或其他安裝錯誤 | 保留錯誤畫面與日誌，依助手提示處理，不要反覆重開原廠安裝器。 |
| 傳統版沒有主畫面 | 先確認已選 **Windows Based Script Host → 一律／Always**，再從桌面開啟。仍失敗時保留錯誤訊息。 |

需要協助時，可到 **[GitHub Issues](https://github.com/root50643/mut3-sew25091-windows11/issues)** 提供錯誤截圖、Windows 版本，以及進行到哪一步。助手的日誌位於 `C:\MUT-Install\oneclick-logs`；分享前請移除個人或車輛資料。
